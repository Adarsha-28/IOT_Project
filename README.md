# IoT-Based Server Room Temperature Monitoring and Warning System

This repository contains the complete college project:
- **`server-room-monitoring/client`**: React.js + Vite + Tailwind CSS + Recharts + Lucide React Dashboard
- **`server-room-monitoring/server`**: Node.js + Express.js REST API + MongoDB Mongoose backend
- **`server-room-monitoring/esp32`**: Arduino C++ firmware sketch for ESP32 DevKit V1 and DHT11

## Quick Start

### 1. Start the Backend
```bash
cd server-room-monitoring/server
npm run dev
```

### 2. Start the Frontend Dashboard
```bash
cd server-room-monitoring/client
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

For full documentation and hardware schematics, refer to [server-room-monitoring/README.md](file:///c:/Users/ADARSHA/Desktop/IOT/server-room-monitoring/README.md).
